# meili-orm M0–M3 实施计划（MeiliSearch Spring Boot Starter）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `com.meilisearch.sdk:meilisearch-java:0.21.0` 封装为类 Spring Data ES 的 Spring Boot Starter（注解映射 + settings 投影同步 + 模板 Operations + 自动配置），单代码库同时兼容 Spring Boot 3.5.x 与 4.x。

**Architecture:** 三层模块（core 零 Spring / autoconfigure 只碰两代 Boot 稳定底座 / starter 聚合），实体↔JSON 全走自有 `MeiliDocumentSerializer`（raw 通道绕开 SDK 内部 Gson），"映射"落地为 **settings 投影**（不标注=不声明）。兼容护栏 = it-boot3/it-boot4 双版本编译运行矩阵。

**Tech Stack:** Java 25 构建（字节码 release=17）、Maven 多模块、meilisearch-java 0.21.0、Jackson 2、Spring Boot 3.5.16/4.0.3、JUnit 5 + AssertJ + Mockito、Testcontainers（`getmeili/meilisearch:v1.49.0`）。

### Task 2: spikeA —— 自定义 JsonHandler 下 SDK 内部模型兼容性

**Files:**
- Create: `meili-orm-core/src/test/java/io/github/lamspace/meili/core/spike/SpikeAJsonHandlerIT.java`
- Modify: `docs/spikes.md`（追加结论）

**Interfaces:**
- Consumes: Task 1 的 `MeiliContainer`。
- Produces: 书面结论决定 M2 的 Client 装配是否注入 JsonHandler（spec §3.4 spikeA）：**预期结论倾向**——SDK 内部模型（`Settings`/`TaskInfo`/`Key`/`Result`）依赖 `GsonJsonHandler` 注册的 typeAdapter 与字段名巧合，自定义 handler 有解析风险 → 读路径全部走 raw 字符串（spikeB 验证），Client 保持默认 GsonJsonHandler。测试代码以"证伪/证实"两种方式都写：用**故意残缺的自定义 handler**（只统计调用次数、委托 Gson 兜底）跑 SDK 全模型解析，断言哪些环节经过了自定义 handler。

**背景事实（执行者需要）**：写/搜主链路我们**只用返回原始字符串的 SDK API**（`updateDocuments(String)`、`rawSearch(SearchRequest)`、`getDocument(String)` 等），JsonHandler 只影响 `getDocument(id, Class)`、`getSettings()` 等 typed 便捷 API。本 spike 回答：① typed API 在默认 GsonJsonHandler 下是否都正常（对照组）；② 注入 JacksonJsonHandler 后 `getSettings`/任务模型是否仍正常（实验组）。

```java
package io.github.lamspace.meili.core.spike;

import com.google.gson.GsonBuilder;
import com.meilisearch.sdk.Client;
import com.meilisearch.sdk.Config;
import com.meilisearch.sdk.Index;
import com.meilisearch.sdk.json.GsonJsonHandler;
import com.meilisearch.sdk.json.JacksonJsonHandler;
import com.meilisearch.sdk.model.*;
import io.github.lamspace.meili.core.AbstractMeiliIntegrationTest;
import org.junit.jupiter.api.*;
import java.util.List;
import java.util.Map;

import static org.assertj.core.api.Assertions.*;

/** spikeA：JsonHandler 注入兼容性实证（spec §3.4）。结论记入 docs/spikes.md。 */
class SpikeAJsonHandlerIT extends AbstractMeiliIntegrationTest {

    private static final String SAMPLE_DOC =
        "{\"id\":9007199254740993,\"title\":\"三体\",\"genre\":\"科幻\"}"; // >2^53 的 Long，兼测精度

    private void exercise(Client client, String uid) throws Exception {
        Index index = client.index(uid);
        TaskInfo t = index.addDocuments("[\"" + "PLACEHOLDER" + "\"]".replace("\"PLACEHOLDER\"", SAMPLE_DOC));
        assertThat(t.getTaskUid()).isNotNull();
        Task done = client.waitForTask(t.getTaskUid());
        assertThat(done.getStatus()).isEqualTo(TaskStatus.SUCCEEDED);
        Settings s = new Settings();
        s.setFilterableAttributes(new String[]{"genre"});
        TaskInfo t2 = index.updateSettings(s);
        client.waitForTask(t2.getTaskUid());
        Settings read = index.getSettings();
        assertThat(read.getFilterableAttributes()).containsExactly("genre");
        assertThat(index.getDocument("9007199254740993", Map.class).get("id"))
            .isNotNull(); // Gson 通道数字精度问题在此暴露（Map 里变 Double）——只记录，不断言
    }

    @Test @DisplayName("对照组：默认 GsonJsonHandler 全模型解析正常")
    void gsonHandlerBaseline() throws Exception { exercise(client(), "spikeA_gson"); }

    @Test @DisplayName("实验组：JacksonJsonHandler 下 settings/task 模型解析")
    void jacksonHandler() throws Exception {
        Config config = new Config(com.meilisearch.sdk.internal.tools.Constants.HOST_URL_FALLBACK != null
                ? MeiliContainer.url() : "", MeiliContainer.MASTER_KEY, new JacksonJsonHandler());
        exercise(new Client(config), "spikeA_jackson");
    }
}
```

```java
    /** 文档中的最终字段名：@MeiliField.name 优先，其次 @JsonProperty，再次 Java 名；两者冲突抛 MeiliMappingException。 */
    public static String docName(AccessibleObject member, String javaName) {

        JsonProperty p = member.getAnnotation(JsonProperty.class);
        if (p != null && !p.value().isEmpty() && !JsonProperty.USE_DEFAULT_NAME.equals(p.value())) jp = p.value();

        }

    }
```

```java
public class Jackson2DocumentSerializer implements MeiliDocumentSerializer {
    private static final class MeiliNameIntrospector extends JacksonAnnotationIntrospector {
        @Override public com.fasterxml.jackson.databind.PropertyName findNameForSerialization(Annotated a) {
            String n = meiliName(a); return n != null ? new com.fasterxml.jackson.databind.PropertyName(n) : super.findNameForSerialization(a); }
        @Override public com.fasterxml.jackson.databind.PropertyName findNameForDeserialization(Annotated a) {
            String n = meiliName(a); return n != null ? new com.fasterxml.jackson.databind.PropertyName(n) : super.findNameForDeserialization(a); }
        private String meiliName(Annotated a) {
            AccessibleObject src = (a instanceof AnnotatedMember m && m.getMember() instanceof AccessibleObject ao) ? ao : null;
            // 对 record 组件：a 是 AnnotatedMethod/AnnotatedField，取其 underlying 上的注解；找不到再看 AnnotatedParameter 等
            if (src == null) return null;
            MeiliField f = src.getAnnotation(MeiliField.class);
            return (f != null && !f.name().isEmpty()) ? f.name() : null;
        }
    }
    private final ObjectMapper mapper;
    public Jackson2DocumentSerializer(ObjectMapper base) {
        this.mapper = base.copy()
            .registerModule(new SimpleModule("meili-orm").setAnnotationIntrospector(new MeiliNameIntrospector()))
            .registerModule(new com.fasterxml.jackson.datatype.jsr310.JavaTimeModule())
            .configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false)
            .configure(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS, false);
    }
    @Override public String write(Object d) { try { return mapper.writeValueAsString(d); } catch (Exception e) { throw new MeiliOrmException("序列化文档失败: " + d.getClass(), e); } }
    @Override public <T> T read(String json, Class<T> t) { try { return mapper.readValue(json, t); } catch (Exception e) { throw new MeiliOrmException("反序列化文档失败: " + t, e); } }
}
```

> introspector 与 `MeiliNames.docName` 的取注解路径必须一致（record 组件、字段、getter 三处都探一次）。若 `@MeiliField` 因 `@Target(FIELD)` 拿不到 getter 注解：统一在**字段/组件**上取，测试覆盖 POJO + record 两形态。
