# docs/internal — Non-deliverable process materials

This directory holds process artifacts: the initial design document, the M0–M3 implementation
plan, the read/write-channel spike evidence archive, and an upstream issue draft that was never
submitted. They record *why* the project took this shape, but they are **not user-facing
documentation** — start from the root [`README.md`](../../README.md) and the [`docs/`](../)
guides instead; no deliverable document presumes these materials.
